Apache Asyncband™ (Incubating) Downloads

Official Apache source releases​

Apache Asyncband™ (Incubating) software provides composable, runtime-agnostic concurrency primitives for async Rust. Its official distribution channel is the source release published through the ASF distribution system. The project maintains the current release line with monotonic releases rather than backporting to older release branches.

The latest official release is 0.8.0:

Verifying a release​

Always verify the integrity of downloaded artifacts using the PGP signatures or SHA-512 checksums hosted on downloads.apache.org:

# Import the release managers' public keys once:
curl -O https://downloads.apache.org/incubator/asyncband/KEYS
gpg --import KEYS

# Verify the detached PGP signature and SHA-512 checksum:
gpg --verify apache-asyncband-0.8.0-incubating-src.tar.gz.asc apache-asyncband-0.8.0-incubating-src.tar.gz
sha512sum -c apache-asyncband-0.8.0-incubating-src.tar.gz.sha512

For full instructions, refer to the Apache guide on verifying the integrity of Apache project releases.

Rust convenience packages​

For day-to-day Rust development, Apache Asyncband (Incubating) also publishes convenience packages to crates.io built from the official source release. These packages supplement the official Apache source release rather than replacing it:

cargo add asyncband --features mutex
  • Crate page: asyncband on crates.io
  • API documentation: docs.rs/asyncband
  • Release notes: GitHub releases and CHANGELOG.md

Historical releases​

Older source releases remain permanently available from the Apache archive. Upgrade to the latest release unless you have a specific constraint.

Apache Asyncband (Incubating) is an effort undergoing incubation at the Apache Software Foundation (ASF), sponsored by the Apache Incubator PMC. Incubation is required of all newly accepted projects until a further review indicates that the infrastructure, communications, and decision making process have stabilized in a manner consistent with other successful ASF projects. While incubation status is not necessarily a reflection of the completeness or stability of the code, it does indicate that the project has yet to be fully endorsed by the ASF.
