# Community Report & Maturity Assessment

> **Updated at: 2026-11-22.** This page is a point-in-time community report and self-assessment prepared during the graduation readiness review of Apache Asyncband (Incubating) ([apache/asyncband#422](https://github.com/apache/asyncband/issues/422)) rather than a continuously updated dashboard. After graduation, individual counts and links may become historical; refer to the [Community](/community/) and [Downloads](/downloads/) pages and the [GitHub repositories](https://github.com/apache/asyncband) for current project state.

## Incubation community summary

Apache Asyncband (Incubating) entered the Apache Incubator on 2026-08-18 following the [proposal discussion](https://lists.apache.org/thread/f31qd3jm3odomjwy3lqkk21coyqsr9xs) and [acceptance vote](https://lists.apache.org/thread/3txlwbp683p9dswwypcdqqq1863khgj5). VP, Brand Management approved the "Apache Asyncband" name in [PODLINGNAMESEARCH-257](https://issues.apache.org/jira/browse/PODLINGNAMESEARCH-257), and initial contributions are covered through contributor ICLAs along the CLA-based path in the [Podling IP Clearance guide](https://incubator.apache.org/guides/ip_clearance.html), recorded on the [Incubator status page](https://incubator.apache.org/projects/asyncband.html).

Over the same period, the PPMC elected three new committers and PPMC members: Bohao Zhang (iqwqi), Yijun Zhao (ariesdevil), and Jinlin Zhu (nanami). The ten-member PPMC and committer roster spans multiple legally independent employers, open-source communities, and individual contributors, with no single organization holding control.

Day-to-day maintenance is shared across committers and contributors, covering release management, concurrency primitive and channel development, code reviews, benchmarking, and website and blog maintenance, with design discussions and roadmaps coordinated in public on GitHub and the project mailing list.

## Apache Project Maturity Model assessment

The tables below evaluate Apache Asyncband (Incubating) against the [Apache Project Maturity Model](https://community.apache.org/apache-way/apache-project-maturity-model.html). Feedback and updates from PPMC members, mentors, and the wider community are welcome on the [development mailing list](/community/#mailing-lists).

| ID       | Description                                                                                                                                                                                                                                                    | Status                                                                                                                                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CD10** | The project produces Open Source software for distribution to the public, at no charge.                                                                                                                                                                        | **YES.** Source code in [apache/asyncband](https://github.com/apache/asyncband) and [apache/asyncband-site](https://github.com/apache/asyncband-site) is distributed publicly at no charge under the Apache License 2.0.               |

| **CD30** | Anyone using standard, widely-available tools, can build the code in a reproducible way.                                                                                                                                                                       | **YES.** The Rust crate builds and tests reproducibly with stable Cargo (MSRV 1.86.0) as documented in the [repository README](https://github.com/apache/asyncband/blob/main/README.md), and the website builds with pnpm and Node.js. |
| **CD40** | The full history of the project's code is available via a source code control system, in a way that allows anyone to recreate any released version.                                                                                                            | **YES.** Full Git commit history and release tags (0.7.2 through 0.8.0) are publicly available in ASF-hosted Git repositories.                                                                                                         |
| **CD50** | The source code control system establishes the provenance of each line of code in a reliable way, based on strong authentication of the committer. ### Licenses and copyright

| ID       | Description                                                                                                                                                                       | Status                                                                                                                                                                                                                                                       |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **LC10** | The Apache License, version 2.0, covers the released code.                                                                                                                        | **YES.** Released archives and repositories carry [LICENSE](https://github.com/apache/asyncband/blob/main/LICENSE) and [NOTICE](https://github.com/apache/asyncband/blob/main/NOTICE), with ASF license headers enforced automatically in CI.                |
| **LC20** | Libraries that are mandatory dependencies of the project's code do not create more restrictions than the Apache License does.                                                     | **YES.** Asyncband enables zero features by default and depends only on the Rust standard library unless optional primitives are selected; optional dependencies use permissive Apache-2.0 or MIT licenses, audited during every release.                    |
| **LC30** | The libraries mentioned in LC20 are available as Open Source software.                                                                                                            | **YES.** All optional crate and build dependencies are OSI-approved open-source packages published on crates.io or npm.                                                                                                                                      |
| **LC40** | Committers are bound by an Individual Contributor Agreement (the "Apache iCLA") that defines which code they may commit and how they need to identify code that is not their own. | **YES.** All ten committers have signed Apache ICLAs on file, verified against ASF ICLA and LDAP records on the [Incubator status page](https://incubator.apache.org/projects/asyncband.html).                                                               |
| **LC50** | The project clearly defines and documents the copyright ownership of everything that the project produces.                                                                        | **YES.** Source files carry standard ASF headers, incorporated third-party notices are preserved and audited per release, and initial CLA-based provenance is recorded on the [Incubator status page](https://incubator.apache.org/projects/asyncband.html). |
