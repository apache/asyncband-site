Available APIs

The crate enables no APIs by default. Categories describe each API's primary purpose and do not add another module level.

Shared state

APIFeaturePurpose
Mutex
asyncband::mutex::Mutex		mutexProtect shared data with asynchronous mutual exclusion.
RwLock
asyncband::rwlock::RwLock		rwlockAllow multiple readers or one writer.
Condvar
asyncband::condvar::Condvar		condvarWait for notifications while releasing a mutex.

One-time initialization

APIFeaturePurpose
Once
asyncband::once::Once		onceRun asynchronous initialization exactly once.
OnceCell
asyncband::once::OnceCell		once-cellInitialize and store one asynchronous value.
OnceMap
asyncband::once::OnceMap		once-mapInitialize and store one value per key.

APIFeaturePurpose

Blocking Interoperability

The optional blocking module bridges synchronous Rust code to runtime-agnostic futures. It is an interoperability utility rather than another async primitive, so it is documented separately from the tables above.

cargo add asyncband --features blocking

See Runtime and Blocking for the execution model and constraints.
